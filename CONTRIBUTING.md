# Lodil’e katkı

Kod MIT lisanslıdır. Windows ve Android için aynı İngilizce → Türkçe deneyimini koruyan hata düzeltmeleri, erişilebilirlik, performans ve dokümantasyon katkıları kabul edilir.

1. Model dosyalarını `python3 scripts/fetch-assets.py` ile al; özet kontrolü için `--check` kullan.
2. Değişikliğe uygun yerel testleri çalıştır: [geliştirme ve test komutları](docs/GELISTIRME.md).
3. PR’da hangi sorunu çözdüğünü, test sonucunu ve gerçek cihazda doğrulamadığın noktaları belirt.

GitHub Actions iş akışı ekleme. APK, Windows dağıtımı ve büyük ONNX modellerini Git geçmişine ekleme. İmza anahtarlarını, sunucu anahtarlarını, özel ekran görüntülerini veya kişisel verileri paylaşma.

Çeviri/OCR sorunu bildirirken cümleyi, beklenen anlamı, platformu, sürümü ve ekran alanı ayarlarını yaz. Görsel gerekiyorsa sadece paylaşmaya yetkili olduğun örnek metni kullan.
