# Ludil v0.4.0 — unpublished development preview

**Status:** locally prepared; not a published GitHub release. The latest published preview remains v0.3.0. Publish only after reviewing the [local verification and outstanding device checks](../TESTLER.md).

- Corrects the displayed application name to **Ludil** on Windows and Android. Existing published download addresses remain intact.
- Adds a dedicated menu/settings reading mode to both applications, including a shared English-to-Turkish glossary for New Game, Continue, Settings and common setting labels/values. Unknown short lines use the configured translator; local translation is the default.
- Adds a separate menu translation panel and contrast processing for selected menu rows. Menus are read from pixels; game files and buttons are not modified.
- Retains subtitle mode, Android update identity/signing key, Windows legacy-settings loading and local pairing.
- Provides a complete English default README and matching Turkish README with language navigation, verified published download links, privacy, limitations and contribution instructions.
- Adds local C#/Java menu regressions and three reproducible synthetic-video scenarios. No GitHub Actions is used.

Prepared filenames: `Ludil-0.4.0-Android.apk`, `Ludil-0.4.0-Windows-x64.zip` and `Ludil-0.4.0-SHA256SUMS.txt`. They are not advertised as public downloads before publication. Existing v0.3.0 assets are unchanged.

Host inference, protocol, component-video and layout checks passed. Native Windows capture and physical Android/TCL/PlayStation workflows remain unverified. The Windows executable is unsigned by Authenticode. The Android APK retains the previous release certificate and uses versionCode 4.
